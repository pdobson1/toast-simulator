# The emulator

The play page runs the ROM in [EmulatorJS](https://emulatorjs.org) 4.2.3 with the Genesis Plus GX core, copied here from npm (`@emulatorjs/emulatorjs` and `@emulatorjs/core-genesis_plus_gx`), so the page always uses the version it was tested with.

- EmulatorJS is under the GPL 3.0: `LICENSE-EmulatorJS.txt`.
- Genesis Plus GX is free for non-commercial use: `LICENSE-GenesisPlusGX.txt`.

Only what the page needs is here: the scripts, the 7z extractor, the translations and the two non-threaded cores.
